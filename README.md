# 펀치카드

팀 출퇴근 기록장. GitHub Pages에 올려서 씁니다.

**팀 규칙**

1. 주 60시간 (식사 시간 제외)
2. 코어타임 13:00~18:00 — 원칙적으로 필수지만 시스템은 막지 않고 경고만 남깁니다
3. 일요일·월요일·화요일은 무조건 근무. 휴무는 수~토 4일 중 하루이며, 해당 주 월요일 안에 고지
4. 점심·저녁은 시작/종료를 따로 찍어 근무시간에서 제외
5. 퇴근 후 재출근(2차 출근) 가능, 자정을 넘기면 날짜가 자동으로 나뉨
6. 지난주에 60시간을 못 채웠으면 모자란 만큼이 이번 주 목표에 더해집니다 (바로 전 주 것만)


---

## 쓰는 법

- 상단 **+ 팀원 추가** 로 이름과 **비밀번호 4자리**를 정해 등록합니다
- 각자 **자기 이름 칩**을 누르고 비밀번호를 넣어 잠금을 풉니다 (브라우저가 기억하므로 한 번만 하면 됩니다)
- 잠긴 팀원은 이름 앞에 🔒 가 붙고, 그 사람 기록은 읽기만 됩니다
- 잘못 만든 팀원은 **+ 팀원 추가** 안의 목록에서 **삭제** 할 수 있습니다 (그 팀원의 비밀번호 필요)
- 큰 버튼으로 **출근 / 식사 시작 / 식사 종료 / 퇴근**
- 퇴근 후 다시 나오면 **2차 출근** 버튼이 살아납니다
- 놓친 시간은 **팀 주간 보드에서 해당 칸을 클릭** → 아래 기록 상세에서 직접 고칩니다
- **이번 주 휴무** 에서 수~토 중 하루를 고릅니다. 월요일 안에 고르면 "사전 고지 완료" 로 표시됩니다

팀원의 변경은 15초마다, 그리고 탭으로 돌아올 때 자동으로 반영됩니다.

## 알아둘 점

- **비밀번호 4자리는 실수 방지용이지 진짜 보안이 아닙니다.** 경우의 수가 1만 개뿐이고 해시도 저장소에 함께 들어 있어서, 마음먹고 뚫으려는 사람은 막지 못합니다. 팀 안에서 남의 기록을 잘못 건드리는 것을 막는 용도로만 쓰세요.
- 비밀번호를 잊으면 되돌릴 방법이 없습니다. 그 팀원을 지우고 다시 만들어야 하며 기록도 함께 사라집니다.
- 이월은 **바로 전 주 것만** 더합니다. 전 주에 기록이 아예 없으면(합류 전) 이월하지 않습니다.
- 시크릿 창처럼 사이트 데이터가 막힌 환경에서는 탭을 닫을 때마다 암호를 다시 물어봅니다. 기록 자체는 서버에 있으니 안전합니다.
- 두 사람이 거의 동시에 저장하면 나중 사람이 서버 내용을 받아 그 위에 자기 변경만 다시 얹습니다. 서로의 기록이 사라지지 않습니다.
- 페이지를 고치면 `index.html` 의 `APP_VERSION` 과 `worker.js` 의 `MIN_CLIENT` 를 함께 올리세요. 그러면 열어둔 옛 탭은 저장이 거부되고 스스로 새로고침해 최신 코드를 받습니다. 이 장치가 없으면 옛 탭이 계속 옛 코드로 돌면서 데이터를 망가뜨립니다.
- 자정을 넘긴 근무는 시작한 날이 `23:59` 로 마감되고 다음 날 `00:00` 출근으로 이어집니다. 이틀 이상 퇴근을 잊은 기록은 그 날만 마감하고 이후 날짜를 만들지 않습니다 — 이 경우 경고가 뜨니 직접 고쳐주세요.
