# 펀치카드

팀 출퇴근 기록장. GitHub Pages에 올려서 씁니다.

**팀 규칙**

1. 주 60시간 (식사 시간 제외)
2. 코어타임 13:00~18:00 — 원칙적으로 필수지만 시스템은 막지 않고 경고만 남깁니다
3. 일요일·월요일·화요일은 무조건 근무. 휴무는 수~토 4일 중 하루이며, 해당 주 월요일 안에 고지
4. 점심·저녁은 시작/종료를 따로 찍어 근무시간에서 제외
5. 퇴근 후 재출근(2차 출근) 가능, 자정을 넘기면 날짜가 자동으로 나뉨


---

## 쓰는 법

- 상단 **+ 팀원 추가** 로 팀원 이름을 모두 등록합니다
- 각자 **자기 이름 칩**을 누릅니다 (브라우저가 기억하므로 한 번만 하면 됩니다)
- 큰 버튼으로 **출근 / 식사 시작 / 식사 종료 / 퇴근**
- 퇴근 후 다시 나오면 **2차 출근** 버튼이 살아납니다
- 놓친 시간은 **팀 주간 보드에서 해당 칸을 클릭** → 아래 기록 상세에서 직접 고칩니다
- **이번 주 휴무** 에서 수~토 중 하루를 고릅니다. 월요일 안에 고르면 "사전 고지 완료" 로 표시됩니다

팀원의 변경은 15초마다, 그리고 탭으로 돌아올 때 자동으로 반영됩니다.

## 알아둘 점

- 시크릿 창처럼 사이트 데이터가 막힌 환경에서는 탭을 닫을 때마다 암호를 다시 물어봅니다. 기록 자체는 서버에 있으니 안전합니다.
- 두 사람이 거의 동시에 저장하면 나중 사람이 서버 내용을 받아 다시 저장합니다. 기록이 사라지지 않습니다.
- 자정을 넘긴 근무는 시작한 날이 `23:59` 로 마감되고 다음 날 `00:00` 출근으로 이어집니다. 이틀 이상 퇴근을 잊은 기록은 그 날만 마감하고 이후 날짜를 만들지 않습니다 — 이 경우 경고가 뜨니 직접 고쳐주세요.
