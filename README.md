# 펀치카드

팀 출퇴근 기록장. GitHub Pages에 올려서 씁니다.

**팀 규칙**

1. 주 60시간 (식사 시간 제외)
2. 코어타임 13:00~18:00 — 원칙적으로 필수지만 시스템은 막지 않고 경고만 남깁니다
3. 일요일·월요일은 무조건 근무. 휴무는 화~토 5일 중 하루이며, 해당 주 월요일 안에 고지
4. 점심·저녁은 시작/종료를 따로 찍어 근무시간에서 제외
5. 퇴근 후 재출근(2차 출근) 가능, 자정을 넘기면 날짜가 자동으로 나뉨

---

## 1단계 — GitHub Pages에 올리기

1. GitHub에서 저장소를 새로 만듭니다.
   - 주소를 `https://<아이디>.github.io/punchcard/` 로 하려면 이름을 `punchcard`
   - 주소를 `https://<아이디>.github.io/` 로 하려면 이름을 `<아이디>.github.io`
2. `index.html` 을 저장소 최상단에 올립니다. (웹에서 Add file → Upload files 로 해도 됩니다)
3. 저장소 **Settings → Pages** → Source 를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 로 두고 저장합니다.
4. 1~2분 뒤 주소가 열립니다.

이 상태로도 바로 쓸 수 있지만, **기록이 그 브라우저에만 저장됩니다.** 팀원끼리 공유하려면 2단계가 필요합니다.

> GitHub Pages는 파일을 보여주기만 하고 데이터를 받아주지 않습니다. 여러 사람이 같은 기록을 보려면 저장을 받아줄 곳이 하나 있어야 합니다. 아래 둘 중 하나만 하면 됩니다. 둘 다 무료입니다.

---

## 2단계 — 팀 공용 저장소 붙이기 (둘 중 하나)

### 방법 A. Cloudflare Workers (권장)

응답이 빠르고 안정적입니다. 카드 등록 없이 무료 플랜으로 충분합니다.

1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입 → **Workers & Pages → Create → Worker** → 이름 `punchcard` → Deploy
2. **Edit code** 를 눌러 `worker.js` 내용을 통째로 붙여넣고 Deploy
3. 좌측 **Storage & Databases → KV → Create a namespace** → 이름 `punchcard-kv`
4. Worker 의 **Settings → Bindings → Add → KV namespace**
   - Variable name: `PUNCHCARD` (이 이름이어야 합니다)
   - KV namespace: 방금 만든 `punchcard-kv`
5. 같은 Settings 에서 **Variables and Secrets** 에 두 개를 추가합니다.
   - `TEAM_KEY` — 팀에서 정한 암호 (Secret 으로)
   - `ALLOW_ORIGIN` — `https://<아이디>.github.io` (경로 없이 도메인만)
6. Worker 주소(`https://punchcard.<계정>.workers.dev`)를 복사합니다.

### 방법 B. Google Apps Script

구글 계정만 있으면 됩니다. 대신 응답이 조금 느립니다.

1. [script.google.com](https://script.google.com) → 새 프로젝트
2. `apps-script.gs` 내용을 붙여넣고, 맨 위 `TEAM_KEY` 를 팀 암호로 바꿉니다
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 배포 후 나오는 `.../exec` 주소를 복사합니다

## 3단계 — 주소 연결

`index.html` 맨 위 한 줄만 고칩니다.

```js
var CONFIG = {
  apiUrl: "https://punchcard.내계정.workers.dev"   // 2단계에서 복사한 주소
};
```

고친 파일을 다시 올리면 끝입니다.

**팀 암호는 여기에 적지 않습니다.** 저장소가 공개라 코드에 적으면 누구나 볼 수 있습니다. 대신 각자 처음 들어올 때 화면에서 한 번 입력하고, 그 브라우저가 기억합니다. 암호는 팀 단톡방 같은 곳으로 따로 전달하세요.

## 쓰는 법

- 상단 **+ 팀원 추가** 로 팀원 이름을 모두 등록합니다
- 각자 **자기 이름 칩**을 누릅니다 (브라우저가 기억하므로 한 번만 하면 됩니다)
- 큰 버튼으로 **출근 / 식사 시작 / 식사 종료 / 퇴근**
- 퇴근 후 다시 나오면 **2차 출근** 버튼이 살아납니다
- 놓친 시간은 **팀 주간 보드에서 해당 칸을 클릭** → 아래 기록 상세에서 직접 고칩니다
- **이번 주 휴무** 에서 화~토 중 하루를 고릅니다. 월요일 안에 고르면 "사전 고지 완료" 로 표시됩니다

팀원의 변경은 15초마다, 그리고 탭으로 돌아올 때 자동으로 반영됩니다.

## 알아둘 점

- **팀 암호를 아는 사람은 기록을 고칠 수 있습니다.** 팀 내부용으로는 충분하지만 민감한 정보는 넣지 마세요. 암호를 `index.html` 에 적어 올리면 공개 저장소에 그대로 노출되니 절대 적지 마세요.
- 시크릿 창처럼 사이트 데이터가 막힌 환경에서는 탭을 닫을 때마다 암호를 다시 물어봅니다. 기록 자체는 서버에 있으니 안전합니다.
- 두 사람이 거의 동시에 저장하면 나중 사람이 서버 내용을 받아 다시 저장합니다. 기록이 사라지지 않습니다.
- 자정을 넘긴 근무는 시작한 날이 `23:59` 로 마감되고 다음 날 `00:00` 출근으로 이어집니다. 이틀 이상 퇴근을 잊은 기록은 그 날만 마감하고 이후 날짜를 만들지 않습니다 — 없는 근무가 생기지 않게 하기 위해서입니다. 이 경우 경고가 뜨니 직접 고쳐주세요.
